ABOUT ME

Hành trình học tập và phát triển.

Từng bước xây dựng kiến thức lập trình, kỹ thuật phần mềm và quy trình triển khai ứng dụng.

Giới thiệu bản thân

Mình là Chu Lam Phuong, sinh viên định hướng phát triển kiến thức về kỹ thuật phần mềm và công nghệ.

Mình quan tâm đến cách các nhóm phát triển quản lý mã nguồn, kiểm thử phần mềm và tự động hóa quá trình đưa sản phẩm lên môi trường triển khai.

Mục tiêu học tập

  • Nắm vững HTML, CSS và kiến thức phát triển website.
  • Sử dụng Git và GitHub để quản lý mã nguồn.
  • Hiểu các bước cơ bản trong quy trình CI/CD.
  • Thực hành kiểm tra chất lượng website bằng Lighthouse CI.
  • Cải thiện khả năng phân tích lỗi và viết tài liệu kỹ thuật.

Nội dung DevOps Lab 1

  • Tạo và quản lý repository trên GitHub.
  • Chỉnh sửa website và lưu lịch sử bằng Git commit.
  • Đẩy mã nguồn lên nhánh GitHub.
  • Kiểm tra chất lượng website với Lighthouse CI.
  • Xuất bản website tĩnh bằng GitHub Pages.

Định hướng tiếp theo

Tiếp tục tìm hiểu JavaScript, kiểm thử phần mềm, tự động hóa quy trình build và deploy, cũng như các nguyên tắc bảo trì phần mềm.
